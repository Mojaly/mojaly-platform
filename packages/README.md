# Packages

Shared libraries live here. These packages should not contain product-specific runtime state.

Planned packages:

- `shared-types` - TypeScript types and API contracts.
- `shared-config` - common configuration loading and validation.
- `shared-db` - database helpers and migration utilities.
- `shared-auth` - authentication helpers for internal services and API keys.
- `shared-errors` - consistent error codes and response shapes.
